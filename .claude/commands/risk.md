Read one risk in full before saying anything about it. Summarise the rating trend, which controls are weak, what treatment is open and any incidents since the last review.

Run: `node scripts/risk.mjs risk`. Add `--json` for structured results.

The CLI output is the source. If a name matches more than one record, show the candidates and ask; an error is never permission to use a different record. Nothing here sends, lodges, pays or deletes.
