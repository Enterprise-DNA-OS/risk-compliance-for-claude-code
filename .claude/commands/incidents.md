The open incident register with every notice clock that is running. Read the APRA 24-hour and 72-hour columns and the privacy columns first. If a clock is running, say the exact time it ends and who owns it.

Run: `node scripts/risk.mjs incidents`. Add `--json` for structured results.

The CLI output is the source. If a name matches more than one record, show the candidates and ask; an error is never permission to use a different record. Nothing here sends, lodges, pays or deletes.
