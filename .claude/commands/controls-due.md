The control testing schedule: tests overdue or due inside the window. Default 30 days. Name the tester and the evidence each test needs.

Run: `node scripts/risk.mjs controls-due`. Add `--json` for structured results.

The CLI output is the source. If a name matches more than one record, show the candidates and ask; an error is never permission to use a different record. Nothing here sends, lodges, pays or deletes.
